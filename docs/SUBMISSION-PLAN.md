## 4. 演示视频结构

唯一讲稿为 `docs/DEMO-SCRIPT.md`；`docs/PITCH-NARRATIVE.md` 仅保留为历史稿，禁止用于录制或现场路演：

- 0:00–0:35 问题与双命题。
- 0:35–1:25 Agent 接住完整任务。
- 1:25–2:20 两次操作追到原始证据。
- 2:20–3:20 人工判断与来源变化精确传播。
- 3:20–4:00 生成可编辑成果。
- 4:00–4:40 非黄金问题诚实拒答并列出缺口。
- 4:40–5:00 收束独特价值。

录制前必须完成三次真实彩排。视频中明确显示离线快照，不声称实时网络或生产部署。

## 6. 提交前证据包

- 最终源码 commit、分支、dirty 状态。
- 安全源码 ZIP 大小与 SHA-256。
- 干净目录门禁日志。
- 三连跑时间与结果。
- PPTX 大小、SHA-256、Microsoft PowerPoint 打开/编辑证据。
- 实时信源发现/核验和单端点在线 LLM 的独立成功/失败证据；不以离线快照替代。
- 上传入口从浏览器到持久化复核的真实闭环证据；“已保存”与“进入证据链”分别验证。
- 项目图片与演示视频 SHA-256。
- 凭据扫描与依赖审计。
- ChatGPT Pro 对话链接与独立修正记录。
- 未验证风险清单。
