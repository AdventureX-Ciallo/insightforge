## 最终量化检查

- 引用定位：黄金案例全部证据路径都能到达原始位置。
- 确定性计算：保留公式、输入、单位、期间和 CSV 行号。
- 无支撑但已确认的结论：0 条。
- 自动修复次数：1 次。
- 黄金 E2E 外部请求：0 次。
- PPTX：5 页；包含可编辑文本元素；溢出问题为 0。
- 后端覆盖率：c8 对 `src/**` 语句、分支、函数与行均为 100%；当前为 197 个顶层 Node 测试、203/203 断言。
- 随机用例/生产源码：770,000/7,690 = 100.13:1；物理 Node/fuzz 测试/生产 TypeScript 行为 8,880/7,690 = 1.155:1，计入 E2E 后为 9,096/7,690 = 1.183:1；这些口径不得混写。
- 实时信源发现：2026-08-29 已对 Bing、Google、百度各执行一次默认 resolver + 默认 `fetch` 的真实只读查询。三者均完成请求；Google 解析出 1 条候选，Bing/百度各为 0 条。0 条响应不能算有效信源成功，进入 COLLECT 前所有结果仍只能是未验证候选。
- 固定白名单核验：必须核验当前白名单响应并保存哈希；任何局部失败持续保留为失败，并与信源发现严格区分。
- 上传覆盖：接受 PDF/CSV/TXT/XLSX；拒绝伪装 PDF、异常 XLSX、路径穿越文件名、NUL/非法 UTF-8 文本和超过 5 MiB 的请求体；持久化文件被篡改时返回 409。
- 问题失配覆盖：输入无关的光伏问题时，3/3 返回 `INSUFFICIENT_EVIDENCE`，不泄漏新能源车结论。
- 在线 LLM：2026-08-29 环境复查确认 API Key、Base URL、Model 三项均不存在，因此没有发起在线请求，也没有用缓存/模拟替代。单端点 PLAN/SYNTHESIZE 的本轮真实外网成功仍未验证；含未知 evidence ID 的单条候选会整体丢弃（不删除坏 ID 后部分放行），其他独立候选继续校验，过滤后少于 3 条使整个 SYNTHESIZE 失败；不得自动切换/降级模型已有本地测试。
- 历史在线 LLM 证据不能证明默认黄金路径消费了真实模型缓存。最终验收必须在 UI 和导出的运行对象中证明候选来源。
- 所有者要求的环境证据：浏览器上传闭环、单一提供方实时搜索、固定白名单实时核验、单端点在线 LLM、Windows Microsoft PowerPoint 打开/编辑/保存/重开，必须分别报告；离线或本地替代不能关闭这些风险。公开部署风险也必须最终核验，但在获得针对具体平台的单独授权前不得执行。
