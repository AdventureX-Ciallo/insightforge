# InsightForge 72 小时最小开发路径

- 状态：`IN EXECUTION — BACKEND VERTICAL SLICE VERIFIED LOCALLY`
- 说明：项目所有者已明确授权继续开发除前端外的范围。阶段 1–4、后端成果版本、安全边界与本地验收已实现；ABloom 负责的前端收口、Windows PowerPoint 和获授权后的部署仍是独立退出条件。

## 原则

- 先冻结可观察结果，再写代码。
- 每一阶段必须有真实入口和失败证据，不能只验证内部函数。
- 先完成一条自然端到端路径，再补局部能力。
- 模型只提出，程序校验，人负责结论。
- 离线稳定性与在线增强分层，不允许静默 fallback。
- 三个核心场景先于功能模块；技术只服务场景。

## 阶段 0：命题研究与产品文档（0–6h，已完成）

交付：双命题调研证据、参考产品方法、产品发现、MVP 策略、黄金案例与来源清单、研究对象/状态/成果版本模型、PRD、范围、用户流程、前端需求、项目说明、决策日志、风险台账、验证计划和 P0 追踪关系。

退出条件：

- 一个产品目标、一个黄金案例、三个核心场景、一个五分钟叙事。
- 十二条 P0 均有可执行验收方式。
- 禁止清单、权限边界和外部环境边界明确。
- 项目所有者明确回复“文档冻结，可以开发”；没有这句话不得进入阶段 1。

## 阶段 1：低保真体验与纵向示踪链（6–16h，后端与当前页面已完成）

交付：三个场景的低保真确认；`PLAN→COLLECT→SYNTHESIZE→AUDIT→DELIVER` 最小链、持久状态、工具事件。

退出条件：一个新任务可以从页面自然跑到终态；故障注入能让步骤失败且阻断交付。

## 阶段 2：证据与真实工具（16–28h，后端已完成）

交付：搜索快照、PDF 页码、CSV 公式、SourceVersion/Source/Locator/Evidence/Datum/Assumption/Claim/EvidenceGap/Conclusion/CandidateRevision 模型。

退出条件：每条结论两次操作内到原始依据；所有公式可重算；提示词注入保持惰性。

## 阶段 3：模型提出与程序校验（28–38h，默认缓存路径已完成；在线端点保留外部配置边界）

交付：

- 真实模型生成并 Schema 约束的离线计划/候选快照；
- 单端点在线模型调用及明确成功/失败证据；
- 单一允许的实时信源发现/搜索与固定白名单来源核验分别记录模式、成功和失败；不做任意爬虫，不静默 fallback；
- evidenceId、状态、数量、工具白名单和问题匹配校验；
- 失配问题进入证据不足，不复用黄金结论。

退出条件：默认黄金路径能证明缓存模型候选来源；在线 LLM 与实时信源发现各有一次成功和一次失败证据；未知 evidenceId、错误工具或配置失败都会阻断。

## 阶段 4：Audit、人工决定与变化（38–48h，后端已完成）

交付：六类输入驱动审查、一次修复、前后差异、确认/驳回/编辑、HumanDecision、ArtifactVersion 与 v1→v2 失效链。

退出条件：补充有效数据会改变 Audit 结果；伪造 ID 不能绕过；编辑不自动确认；更新只影响依赖对象，旧决定和旧成果版本保留。

## 阶段 5：成果与三场景前端（48–58h，后端成果已完成；前端由 ABloom 收口）

交付：由任务、研究报告、变化与交付三层主导航承载的交互报告；五页可编辑 PPTX、证据 JSON；真实上传、在线模型和来源发现/核验作为必须实现和验收、但不争夺主线的次要入口。

退出条件：目标 Windows Microsoft PowerPoint 可打开、编辑、保存、重开；浏览器 E2E 覆盖支持/缺口下钻、人工决定、成果版本、来源更新、上传和下载。

## 阶段 6：安全与现场稳定（58–67h，本地后端门禁已完成，最终干净包复验中）

交付：loopback-only、CSP、安全 DOM、文件字节校验、原子落盘、密钥扫描、离线灾备成果。

退出条件：三连跑成功；现场单次不超过三分钟；攻击与篡改测试 fail-closed。

## 阶段 7：独立验收与封装（67–72h，进行中）

交付：外部审查记录、干净目录回放、最终 ZIP/SHA-256、演示脚本、提交材料草案。

退出条件：

- `npm ci`、完整门禁、E2E、三连跑、生产 smoke、依赖审计全部从最终 ZIP 通过。
- 任何失败、替代验证或外部阻塞写入证据，不把 mock 说成生产。
- 真实上传、实时信源发现、白名单核验、在线 LLM、Windows PowerPoint 与获授权后的部署分别保存证据；缺一项就列为未验证风险，部署未获授权时列为外部阻断。
- 未经授权不 commit、push、Tag 或部署。
